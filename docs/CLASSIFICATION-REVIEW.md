## 真の同義と曖昧語

- Switch / Scissorsは同一ID `rtk:switch-pass`。Snookが局所プレーへ付けたSwitchという名前までは同一視しない。
- Cut-out / Miss passは同一ID `rtk:cut-out-pass`。NZRのMiss Pass Drillが同じ技術をcut-outとも表現する。
- Loop / Run aroundは同一ID `rtk:loop-move`。second touch（再接触）は上位の考え方で、loopと同義ではない。
- Up-and-under / Bombは同一ID `rtk:up-and-under-contest`。資料がこのキック名を明示併記する。
- スクリーン、tip-on、Blitz、数字だけの配置、著者のローカルコールは、意味・範囲が一致する根拠なしに統合しない。

### 日本語「ミスパス」の曖昧性を示す別資料

- 資料: [7人制日本代表「東アジア競技大会」リポート](https://www.rugby-japan.jp/news/4322)
- 発行: 日本ラグビーフットボール協会（JRFU）。表示日2009-12-06、本文確認2026-11-15。
- 箇所: 「●12月3日(木) 女子7人制日本代表」節、パス中心の練習を述べる段落。
- 独自要約: 意思疎通によって減ったパスの不調を「ミスパス」と表現している。意図的に味方を飛ばす技術名とは異なる用法がある。
- この意味の判定は文脈に基づく編集上の解釈。活動報告であり、技術教材・競技規則ではない。記事はsevensの範囲で、XVの技術実証として扱わない。
- 既存dataset v1のsource.kindはcoaching/lawのみのため、記事を誤分類して押し込まず、語義の注意を裏付ける文書資料としてここに記録した。英語Miss passは同義名、日本語ミスパスはcontextualとして一意解決を防ぐ。

## 非同義・包含・関連

三人ポッドと1-3-3-1は構成単位とシステム。プルバックと接触中スクリーンは使う文脈・動作が異なる。
接触前短パスとタックル中パス、undersとovers、sweeper役とpendulum方式、ボックスキックとup-and-underを、共通目的だけで同一にしない。
man-on-manの資料もパス後の担当移動を説明するため、固定担当対driftという二分法を撤回した。
